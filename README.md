# Retail Solutions

A web-based retail management application built with PHP and MySQL.

## Features
- User authentication and session management  
- Admin dashboard for inventory management
- Client portal for order tracking

## Getting Started

1. Configure your database settings in `config.php`
2. Run `php -S localhost:8000` to start the development server
3. Navigate to `http://localhost:8000` in your browser

## Tech Stack
- PHP 7.x
- MySQL 5.7+
- Bootstrap 3.3.5
- jQuery 1.11.3

## Analytics Integration
This project supports Pendo Novus for product analytics.
